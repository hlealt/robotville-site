# robotville-site

Static site for robotville.ai, served by GitHub Pages (repo hlealt/robotville-site, custom domain in `CNAME`).
It exists to satisfy Google OAuth branding for the `second-brain` Google Cloud app (project second-brain-tools-491900):
the home page must name the app exactly as the OAuth consent screen does ("second-brain"), explain its purpose, and link
to `/privacy`. Change the app name here and in the Google console together.
